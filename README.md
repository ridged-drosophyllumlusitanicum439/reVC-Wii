<h2>🆘 Troubleshooting & Help</h2>

<p>Having trouble? Try these quick fixes:</p>

<h3>Game Won't Start</h3>
<ul>
  <li>Make sure your SD card is FAT32 formatted (not exFAT or NTFS).</li>
  <li>Try a different SD card if possible - some cheap cards have compatibility issues.</li>
  <li>Ensure the file is fully copied - check that the file size matches the original download.</li>
</ul>

<h3>Black Screen on Launch</h3>
<ul>
  <li>Your Wii's system menu might be above version 4.3. Update to 4.3 if older, or use the "Loader" mode included.</li>
  <li>Restart your Wii completely (hold power button 4 seconds) and try again.</li>
</ul>

<h3>Sound Problems</h3>
<ul>
  <li>Go to Game Settings in the main menu and switch Audio Output to "Stereo" (not Surround).</li>
  <li>Make sure your AV cables are plugged in securely.</li>
</ul>
